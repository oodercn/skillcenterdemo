# 常见错误排查

## 1. SyntaxError: missing ) after argument list

### 错误描述
JavaScript 语法错误，提示缺少参数列表后的闭合括号。

### 可能原因
1. 函数调用时缺少闭合括号
2. 括号不匹配
3. 字符串或模板字面量中的语法错误
4. 对象字面量或数组字面量中的语法错误

### 解决方案
1. 检查函数调用是否有完整的括号对
2. 检查所有括号是否正确匹配
3. 检查字符串和模板字面量的引号是否正确
4. 使用浏览器开发者工具的控制台查看详细错误信息
5. 利用菜单系统中的语法错误检测机制定位问题

### 预防措施
- 在编写代码时注意括号的匹配
- 使用代码编辑器的语法高亮和错误提示功能
- 定期测试页面功能

## 2. ReferenceError: API_BASE_URL is not defined

### 错误描述
引用错误，提示 API_BASE_URL 未定义。

### 可能原因
1. API_BASE_URL 变量未声明
2. 脚本执行顺序问题
3. 页面加载时脚本执行失败

### 解决方案
1. 确保在使用 API_BASE_URL 前已声明
2. 检查脚本执行顺序
3. 查看浏览器控制台的详细错误信息

### 预防措施
- 在全局范围内声明 API_BASE_URL
- 使用适当的错误处理机制

## 3. TypeError: Cannot read property 'addEventListener' of null

### 错误描述
类型错误，提示无法读取 null 的 addEventListener 属性。

### 可能原因
1. DOM 元素未找到
2. 脚本执行时 DOM 尚未完全加载
3. 元素 ID 拼写错误

### 解决方案
1. 检查元素 ID 是否正确
2. 确保脚本在 DOM 加载完成后执行
3. 使用 document.addEventListener('DOMContentLoaded', function() { ... });

### 预防措施
- 在操作 DOM 元素前检查元素是否存在
- 使用适当的 DOM 加载事件监听器

## 4. Fetch API 错误

### 错误描述
网络请求失败，可能是 404、500 等错误。

### 可能原因
1. API 端点不存在
2. 服务器内部错误
3. 网络连接问题
4. 权限问题

### 解决方案
1. 检查 API 端点 URL 是否正确
2. 查看服务器日志了解具体错误
3. 检查网络连接
4. 确保用户有适当的权限

### 预防措施
- 在代码中添加适当的错误处理
- 测试所有 API 端点
- 提供友好的错误提示给用户

## 5. 页面加载失败

### 错误描述
页面无法正常加载，显示错误信息。

### 可能原因
1. 页面文件不存在
2. 服务器配置错误
3. 脚本执行失败
4. 网络连接问题

### 解决方案
1. 检查页面文件是否存在
2. 查看服务器配置
3. 检查浏览器控制台的错误信息
4. 检查网络连接

### 预防措施
- 确保所有页面文件存在
- 定期测试页面加载功能
- 提供友好的错误提示给用户

## 6. SyntaxError: Identifier 'API_BASE_URL' has already been declared

### 错误描述
JavaScript 语法错误，提示 API_BASE_URL 标识符已被声明。

### 可能原因
1. 多个文件中重复声明了 API_BASE_URL 常量
2. 页面同时引用了多个包含 API_BASE_URL 声明的 JS 文件
3. menu.js 在执行页面脚本时未能正确处理 API_BASE_URL 的重复声明
4. 不同版本的 JS 文件中存在相同的变量声明

### 解决方案
1. 确保只有 utils.js 中声明 API_BASE_URL
2. 检查所有 JS 文件，移除重复的 API_BASE_URL 声明
3. 在 menu.js 中使用正则表达式替换 API_BASE_URL 为 utils.API_BASE_URL
4. 统一使用 utils.API_BASE_URL 而不是直接使用 API_BASE_URL

### 预防措施
- 集中管理 API_BASE_URL，只在 utils.js 中声明一次
- 使用模块化方式导出和导入 API_BASE_URL
- 在开发过程中定期检查变量声明冲突
- 使用代码检查工具（如 ESLint）检测重复声明

### 相关文件
- `/js/utils.js` - 唯一应该声明 API_BASE_URL 的文件
- `/js/menu.js` - 负责处理页面脚本执行，需要正确替换 API_BASE_URL
- `/assets/js/common/api.js` - 已移除 API_BASE_URL 声明
- `/assets/js/app.js` - 包含 API_BASE_URL 声明但未被使用
